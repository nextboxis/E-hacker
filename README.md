**E-HACKER** is a full-scale, production-ready **React 18 + Vite** cybersecurity educational platform, interactive hands-on laboratory, and daily security workstation. Built with modern modular React architecture, serverless Vercel cloud APIs, in-browser Python 3.11 Cyber Lab, an AI Security Suite, and client-side reactive database persistence.

---

## 🌟 Modern React Architecture & Modules

### 1. ⚛️ React 18 + Vite Single Page Application
- **Modern Component Architecture**: Modular layout, tabs, modals, and custom hooks.
- **Unified State Management**: `AuthContext` managing operative identity, multi-profile isolation, XP progression, domain filters, and global keyboard shortcuts (`Ctrl+K`, `Esc`).

### 2. 🐍 Python Cyber Security Lab & Script Runner (`tab-python`)
- **Interactive Python REPL & Exploitation Sandbox**: Run, modify, and simulate real-time Python pentesting, socket scanning, payload encoding, and log forensics scripts in the browser.
- **8 Pre-Configured Python Security Templates**:
  1. *Multi-Threaded TCP Port Scanner* (`socket`, `sys`)
  2. *Cryptographic Hash & Salt Cracker* (`hashlib`, `time`)
  3. *DNS Subdomain Brute-Forcer* (`socket`)
  4. *HTTP Security Headers & CORS Auditor* (`urllib.request`)
  5. *JWT Token Decoder & HMAC Verifier* (`base64`, `json`)
  6. *Syslog & Apache Log Anomaly Parser* (`re`)
  7. *Shellcode XOR & Base64 Payload Encoder* (`bytearray`)
  8. *SQL Injection & XSS Payload Detector* (`re`)
- **Serverless Python 3.11 Runtime Endpoint** (`/api/python-analyzer.py`).

### 3. ⚡ 10x Deauthorization Sequence & Prominent Logout Controls
- **Instant Logout Buttons** available directly in the **Topbar Header**, **Sidebar Navigation Footer**, and **Operative Profile Dossier**.
- **Cinematic Memory Sanitization**: Step-by-step cryptographic zeroization progress bar, mission debrief card, and Emergency Clean Burn reset.

### 4. 🪪 Operative Profile & Multi-User Dossier (`tab-profile`)
- Multi-operative profile management with independent data isolation (XP, completed labs, checked skills, notes).
- 8 Cyber Achievement Badges with real-time unlock tracking.
- Security API Tokens sandbox & JSON dossier backup.

### 5. 🤖 AI Security Suite & Real-Time Threat Radar (`tab-ai-hub`)
- AI Detection Rule Synthesizer (Sigma YAML, Splunk SPL, YARA).
- Live Real-time CVE & Zero-Day Threat Stream.
- Global Attack Telemetry Radar on HTML5 canvas.

### 6. 🧪 Project Hub (100 Hands-on Cybersecurity Labs)
- 100 Curated Labs across Web Hacking, Network Security, Tool Dev, Malware Defense, OSINT, and Active Directory.

### 7. 🛠️ Cyber Toolkit & Offline Mini-Labs
- Multi-Hash Generator & Identifier, Multi-Encoder/Decoder, IPv4 Subnet Calculator, CVSS v3.1 Matrix, Regex Tester, and Cyber Kill Chain explorer.
